# 隐私政策

更新日期：2026 年 9 月 23 日

Douban Book+（以下简称“本扩展”）重视你的隐私。本隐私政策说明本扩展在你使用过程中如何处理信息。

## 我们不要求身份信息

本扩展不要求姓名、电子邮箱、联系方式或账号，也不会收集设备标识符或精确位置信息。我们不会建立完整的浏览历史，也不会识别用户或跨安装跟踪用户。

## 本扩展处理的信息

为了提供电子书搜索功能，本扩展仅会读取当前豆瓣读书页面上公开展示的图书信息，例如：

- 书名
- 作者
- ISBN
- 出版社
- 当前豆瓣读书图书页面的网址
- 其他与识别和搜索该图书直接相关的公开信息

这些信息来自任何访问者均可查看的豆瓣读书公开页面，并通过 HTTPS 发送到我们的电子书搜索 API，仅用于生成或执行当前图书的搜索。扩展不会读取完整浏览历史或其他网站内容，也不会把这些信息用于识别用户、建立用户画像、广告投放或出售给第三方。

## 可选的卸载问卷

卸载 Chrome 扩展后，Chrome 可能会打开我们的[卸载问卷](/uninstall)。是否提交完全自愿，问卷无需登录，也不要求电子邮箱或其他身份信息。

提交问卷时，我们仅保存：

- 你选择的卸载原因
- 你填写的改进建议
- 你自愿填写的其他反馈
- 已卸载的扩展版本号
- 提交时间

请不要在自由文本中填写姓名、电子邮箱或其他个人信息。问卷提交只包含上述字段；不会包含浏览历史、访问过的网址、网页内容、IP 地址、User-Agent、Cookie 或用户/扩展标识符。为防止自动化滥用，服务端会临时读取 Cloudflare 提供的网络地址，并结合当前 UTC 日期生成每日变化的 SHA-256 限流键；原始地址和限流键都不会写入应用日志或数据库。回答存储在 Cloudflare D1 中，仅用于汇总分析重复出现的卸载原因和改进产品；不会用于广告、建立用户画像、跟踪个人或出售给第三方。原始回答最多保留 24 个月，之后删除；汇总后的匿名趋势数据可以长期保留。我们会在至少收到 30 份有效回答后再评估趋势，不会根据少量孤立反馈仓促调整产品。

## 可选的匿名分享功能统计

扩展提供可选的匿名使用统计，用于评估分享功能是否容易发现和使用。该功能默认不上传数据；启用时会请求访问本站的可选权限。Firefox 还会使用浏览器内置的“技术和交互数据”授权，用户可以随时撤销授权。

启用后，扩展仅在本地按 UTC 日期累计并上传以下计数：

- 电子书资源结果展示次数，以及资源数量的粗略区间（0、1、2–3、4–7、8+）
- 分享面板打开次数
- 每次分享面板中首次选择的分享目标及其名称（例如复制、系统分享或某个社交平台）

分享文案中的固定链接带有 `utm_source=extension` 和 `utm_medium=share`。访问该链接时，官网会记录一次分享链接打开；如果随后点击浏览器插件商店链接，还会记录商店类型。统计载荷不会包含书名、ISBN、豆瓣页面网址、分享文案、精确时间、账号、Cookie、IP 地址、User-Agent、设备/安装标识符或完整浏览历史；应用数据库也不会保存 IP 地址、User-Agent 或限流键。为防止自动化滥用，统计服务会使用与问卷相同的每日变化 SHA-256 限流方式，限流键只交给 Cloudflare 的短期限流系统使用，不会用于识别或跨日跟踪用户。

为避免网络重试重复计数，每批汇总使用一个随机且不复用的批次标记；服务端只保存其哈希并在 8 天后删除。事件只以按日汇总的匿名计数保存，用于比较每次资源结果展示对应的分享面板打开次数、分享目标选择率、分享链接打开趋势和插件商店点击趋势。用户可以随时在扩展设置中关闭统计，关闭后扩展会删除尚未上传的本地计数。

## 第三方服务

本扩展会提供指向第三方电子书平台或搜索服务的链接。访问这些第三方网站时，相关网站可能按照其自身的隐私政策处理信息。我们不控制第三方网站的行为，建议你在使用前阅读其隐私政策。

豆瓣及其相关标识属于其各自权利人。本扩展与豆瓣及所链接的第三方平台不存在隶属、授权或背书关系，除非另有明确说明。

官网、可选卸载问卷和可选匿名统计由 Cloudflare 托管。Cloudflare 可能为提供、安全保护和运行该服务而处理必要的网络请求信息；我们不会把问卷回答或匿名统计与该信息组合来识别或跟踪用户。

本扩展对用户数据的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）：仅将数据用于提供或改进公开说明的单一用途，不用于个性化广告、数据经纪或与该用途无关的目的。

## 儿童隐私

本扩展、问卷和匿名统计不面向儿童，也不会有意要求或收集儿童的个人信息。

## 政策更新

如本扩展的功能或信息处理方式发生变化，我们可能更新本隐私政策，并在本页面注明新的更新日期。任何更新均不会追溯性地改变我们对既有信息的处理方式。
