# 隐私政策

更新日期：2026 年 8 月 17 日

Douban Book+（以下简称“本扩展”）重视你的隐私。本隐私政策说明本扩展在你使用过程中如何处理信息。

## 我们不要求身份信息

本扩展不要求姓名、电子邮箱、联系方式或账号，也不会收集设备标识符或精确位置信息。我们不会建立完整的浏览历史，也不会识别用户或跨安装跟踪用户。

## 本扩展处理的信息

为了提供电子书搜索功能，本扩展仅会读取当前豆瓣读书页面上公开展示的图书信息，例如：

- 书名
- 作者
- ISBN
- 出版社
- 当前豆瓣读书图书页面的网址
- 其他与识别和搜索该图书直接相关的公开信息

这些信息来自任何访问者均可查看的豆瓣读书公开页面，并通过 HTTPS 发送到我们的电子书搜索 API，仅用于生成或执行当前图书的搜索。扩展不会读取完整浏览历史或其他网站内容，也不会把这些信息用于识别用户、建立用户画像、广告投放或出售给第三方。

## 可选的卸载问卷

卸载 Chrome 扩展后，Chrome 可能会打开我们的[卸载问卷](/uninstall)。是否提交完全自愿，问卷无需登录，也不要求电子邮箱或其他身份信息。

提交问卷时，我们仅保存：

- 你选择的卸载原因
- 你填写的改进建议
- 你自愿填写的其他反馈
- 已卸载的扩展版本号
- 提交时间

请不要在自由文本中填写姓名、电子邮箱或其他个人信息。问卷提交只包含上述字段；不会包含浏览历史、访问过的网址、网页内容、IP 地址、User-Agent、Cookie 或用户/扩展标识符。回答存储在 Cloudflare D1 中，仅用于汇总分析重复出现的卸载原因和改进产品；不会用于广告、建立用户画像、跟踪个人或出售给第三方。原始回答最多保留 24 个月，之后删除；汇总后的匿名趋势数据可以长期保留。我们会在至少收到 30 份有效回答后再评估趋势，不会根据少量孤立反馈仓促调整产品。

## 第三方服务

本扩展会提供指向第三方电子书平台或搜索服务的链接。访问这些第三方网站时，相关网站可能按照其自身的隐私政策处理信息。我们不控制第三方网站的行为，建议你在使用前阅读其隐私政策。

豆瓣及其相关标识属于其各自权利人。本扩展与豆瓣及所链接的第三方平台不存在隶属、授权或背书关系，除非另有明确说明。

官网和可选卸载问卷由 Cloudflare 托管。Cloudflare 可能为提供、安全保护和运行该服务而处理必要的网络请求信息；我们不会把问卷回答与该信息组合来识别或跟踪用户。

本扩展对用户数据的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）：仅将数据用于提供或改进公开说明的单一用途，不用于个性化广告、数据经纪或与该用途无关的目的。

## 儿童隐私

本扩展和问卷不面向儿童，也不会有意要求或收集儿童的个人信息。

## 政策更新

如本扩展的功能或信息处理方式发生变化，我们可能更新本隐私政策，并在本页面注明新的更新日期。任何更新均不会追溯性地改变我们对既有信息的处理方式。

## 联系我们

如果你对本隐私政策有任何疑问，可通过 [GitHub 项目页面](https://github.com/OldPanda/douban-book-plus-homepage) 联系我们。
