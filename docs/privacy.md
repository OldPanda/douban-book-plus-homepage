# 隐私政策 {#legal-title}

更新日期：2026 年 10 月 9 日

Douban Book+（以下简称“本扩展”）重视你的隐私。本隐私政策说明本扩展在你使用过程中如何处理信息。

## 我们不要求身份信息

本扩展不要求姓名、电子邮箱、联系方式或账号，也不会收集设备标识符或精确位置信息。我们不会建立完整的浏览历史，也不会识别用户或跨安装跟踪用户。

## Firefox 为什么提示“浏览活动”和“网站内容”？

Firefox 在安装或更新扩展时，可能会提示本扩展需要收集“浏览活动”（Browsing activity）和“网站内容”（Website content）。这是 Firefox 对扩展向外传输的数据所使用的分类名称：当前页面的网址属于“浏览活动”，页面上公开展示的书名、ISBN 等图书信息属于“网站内容”。

对于本扩展，这些声明对应的是：当你打开受支持的豆瓣读书图书页面时，扩展会自动将当前图书页面的网址和下文列出的公开图书信息，通过 HTTPS 发送到电子书搜索 API，以查找这本书的电子书资源。该查询不需要你另行点击搜索按钮。

本扩展没有申请读取浏览器历史记录的 `history` 权限，不会读取浏览器保存的历史记录，也不会收集你访问其他网站的网址或建立你的浏览轨迹。上述数据分类声明不代表本扩展获得了读取完整浏览历史的权限。

“网站活动”（Website activity）是 Firefox 的另一种数据分类，涵盖点击、滚动、输入等交互行为；它与“网站内容”不同。本扩展没有声明该类别，也不会监控你在其他网站上的这些行为。分享功能的可选匿名统计及其授权方式见下文说明。

## 本扩展处理的信息

为了提供电子书搜索功能，本扩展会从当前受支持的豆瓣读书图书页面读取并向搜索 API 发送以下信息：

- 书名
- 作者
- ISBN
- 出版社
- 当前豆瓣读书图书页面的网址
- 副标题、译者（页面上存在时）
- 页面上展示的豆瓣阅读、得到电子书链接（页面上存在且受支持时）

这些信息来自任何访问者均可查看的豆瓣读书公开页面，并通过 HTTPS 发送到我们的电子书搜索 API，仅用于生成或执行当前图书的搜索。扩展不会读取完整浏览历史或其他网站内容，也不会把这些信息用于识别用户、建立用户画像、广告投放或出售给第三方。

## 可选的卸载问卷

卸载 Chrome 扩展后，Chrome 可能会打开我们的[卸载问卷](/uninstall)。是否提交完全自愿，问卷无需登录，也不要求电子邮箱或其他身份信息。

提交问卷时，我们仅保存：

- 你选择的卸载原因
- 你填写的改进建议
- 你自愿填写的其他反馈
- 已卸载的扩展版本号
- 提交时间

请不要在自由文本中填写姓名、电子邮箱或其他个人信息。问卷不会自动附带浏览历史、访问过的网址、网页内容、IP 地址、User-Agent、Cookie 或用户/扩展标识符作为回答字段。浏览器发送请求时仍可能携带正常的网络请求头；这些信息不会作为问卷回答字段保存。

为防止自动化滥用，服务端会临时读取 Cloudflare 提供的网络地址，结合表单类型和当前 UTC 分钟，使用仅保存在服务端的密钥生成每分钟变化的 HMAC-SHA-256 限流键。密钥不会写入数据库、应用日志或发送至浏览器。限流键、分钟窗口和通过限流检查的请求次数单独存储于 Cloudflare D1，不与回答关联；原始地址和限流键不写入应用日志，原始地址也不写入数据库。限流计数仅在对应的一分钟内有效；为处理跨分钟的在途请求，保留当前和前一个分钟窗口，更早的计数在后续表单请求时删除。如果没有后续请求，过期记录可能暂留，但不会再用于限流或跨窗口跟踪。

回答存储在 Cloudflare D1 中，仅用于汇总分析重复出现的卸载原因和改进产品；不会用于广告、建立用户画像、跟踪个人或出售给第三方。原始回答的保留期限为最多 24 个月。每日定时任务会删除已到期及将在下一次日常清理前到期的回答，因此可能最多提前一天删除；若任务失败，过期记录会在后续成功执行时清理。汇总后的匿名趋势数据可以长期保留。我们会在至少收到 30 份有效回答后再评估趋势，不会根据少量孤立反馈仓促调整产品。

## 可选的官网反馈

官网提供自愿填写的反馈表单，无需登录，也不要求姓名、邮箱或联系方式。提交前需要确认同意将内容用于处理反馈。请勿填写密码、身份信息或私人通信内容；本表单不提供邮件回复。

我们保存你填写的标题、反馈内容、随机生成的反馈编号、提交与处理时间，以及处理状态。内容先存储在 Cloudflare D1，再由服务端转交维护者的 GitHub 私有仓库，用于创建和跟进问题。反馈不会在官网公开展示；GitHub 中的内容仅对该私有仓库的授权人员可见。官网不会向访客返回私有仓库的内容、访问凭据或 Issue 链接。

为避免网络重试创建重复问题，服务端保存提交内容的 SHA-256 摘要和对应的内部 Issue 编号。为限制滥用，官网反馈采用与上述问卷相同的服务端密钥、每分钟变化的 HMAC-SHA-256 限流键和独立 D1 限流计数，使用不同的表单类型区分，不与反馈内容关联。计数仅在对应的一分钟内有效，保留当前和前一个分钟窗口，更早的计数在后续表单请求时删除；无后续请求时可能暂留过期记录。原始 IP 地址不写入应用数据库或应用日志；限流键也不写入应用日志。原始 IP 和限流键均不转交 GitHub。Cloudflare 和 GitHub 作为服务提供方，会按照各自的服务及隐私政策处理必要信息。

反馈服务开放时，表单会加载 Cloudflare Turnstile 安全验证。浏览器会直接连接 Cloudflare 完成验证，服务端仅向验证接口提交验证令牌和服务端密钥，不发送反馈标题或内容。验证令牌不会保存到反馈数据库、应用日志或 GitHub Issue 中。

反馈及处理记录用于排查问题、跟进建议和避免重复提交，不用于广告或建立用户画像。需要查询或请求删除某条反馈时，可通过本页联系方式提供反馈编号；请勿在公开 Issue 中重复发布反馈中的私人内容。

## 可选的匿名分享功能统计

扩展提供可选的匿名使用统计，用于评估分享功能是否容易发现和使用。该功能默认不上传数据；启用时会请求访问本站的可选权限。Firefox 还会使用浏览器内置的“技术和交互数据”授权，用户可以随时撤销授权。

启用后，扩展仅在本地按 UTC 日期累计并上传以下计数：

- 电子书资源结果展示次数，以及资源数量的粗略区间（0、1、2–3、4–7、8+）
- 分享面板打开次数
- 每次分享面板中首次选择的分享目标及其名称（例如复制、系统分享或某个社交平台）

分享文案中的固定链接带有 `utm_source=extension` 和 `utm_medium=share`。访问该链接时，官网会记录一次分享链接打开；如果随后点击浏览器插件商店链接，还会记录商店类型。统计载荷不会包含书名、ISBN、豆瓣页面网址、分享文案、精确时间、账号、Cookie、IP 地址、User-Agent、设备/安装标识符或完整浏览历史；匿名统计数据库记录也不会保存 IP 地址、User-Agent 或限流键。为防止自动化滥用，独立的统计服务使用每日变化 SHA-256 限流键；该服务的限流键只交给 Cloudflare 的短期限流系统使用，不写入应用数据库，不会用于识别或跨日跟踪用户。

为避免网络重试重复计数，每批汇总使用一个随机批次标记，仅在重试同一批数据时复用，不作为用户或安装标识符。服务端不保存原始批次标记，而是将批次标记、事件序号和来源生成哈希，随事件日期、类型、计数、分享或商店目标、资源数量区间、来源及接收日期保存为短期去重记录。每日定时任务按接收日期清理达到 8 个 UTC 日历日的记录及相应日期的统计接收配额记录；这不是精确到小时的自动过期，若任务失败，记录会在后续成功执行时清理。

长期保留的是按日汇总的匿名计数，用于比较每次资源结果展示对应的分享面板打开次数、分享目标选择率、分享链接打开趋势和插件商店点击趋势。用户可以随时在扩展设置中关闭统计，关闭后扩展会删除尚未上传的本地计数。

## 第三方服务

本扩展会提供指向第三方电子书平台或搜索服务的链接。访问这些第三方网站时，相关网站可能按照其自身的隐私政策处理信息。我们不控制第三方网站的行为，建议你在使用前阅读其隐私政策。

豆瓣及其相关标识属于其各自权利人。本扩展与豆瓣及所链接的第三方平台不存在隶属、授权或背书关系，除非另有明确说明。

官网、可选卸载问卷、官网反馈和匿名分享统计由 Cloudflare 托管。扩展端统计需要用户主动启用；带指定分享参数的官网访问会产生上述引流计数。Cloudflare 可能为提供、安全保护和运行该服务而处理必要的网络请求信息；我们不会把问卷回答或匿名统计与该信息组合来识别或跟踪用户。

本扩展对用户数据的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）：仅将数据用于提供或改进公开说明的单一用途，不用于个性化广告、数据经纪或与该用途无关的目的。

## 儿童隐私

本扩展、问卷和匿名统计不面向儿童，也不会有意要求或收集儿童的个人信息。

## 政策更新

如本扩展的功能或信息处理方式发生变化，我们可能更新本隐私政策，并在本页面注明新的更新日期。任何更新均不会追溯性地改变我们对既有信息的处理方式。

## 联系我们

如果你对本隐私政策有任何疑问，或希望查询、删除已提交的反馈，可通过[官网反馈表单](/#feedback) 给我们留言。涉及已有反馈时，请提供反馈编号，便于维护者查找。

反馈无需登录，不会公开展示。请勿填写密码或其他敏感个人信息；本表单不提供邮件回复。
